# Cadence Planner — вебзастосунок для планування навчання та контролю особистого прогресу

Повноцінний full-stack вебзастосунок (UA / EN) для планування навчання, кар'єри, мов, спорту та особистих проєктів в одному місці: сфери діяльності, курси, завдання з дедлайнами, розклад занять, нагадування та статистика прогресу. Курсовий проєкт.

- **Розробниця:** Дишлюк Анастасія Русланівна, група ІПЗ-41, спеціальність 121 «Інженерія програмного забезпечення».
- **Походження назви:** Cadence — від латинського _cadentia_ та музичного терміна «каданс», тобто гармонійного ритму й вивіреного темпу без вигорання.

---

## Можливості

- **Реєстрація, вхід і відновлення пароля.** Паролі зберігаються як хеші `bcrypt`, доступ до API — через JWT. Кожен користувач бачить і редагує лише власні записи. Забутий пароль відновлюється одноразовим 6-значним кодом, який надсилається на пошту та в Telegram.
- **Сфери → курси → завдання.** Повний CRUD із кольорами й іконками сфер. Після реєстрації автоматично створюються 5 стартових сфер: «Коледж», «FullStack-курси», «Німецька мова», «Робота», «Спорт». Прогрес курсу (% виконаних завдань) і прогрес сфери розраховуються автоматично.
- **Завдання.** Пошук, фільтри (сфера, курс, статус, пріоритет), сортування, повторювані завдання, виділення прострочених.
- **Календар.** Заняття (зокрема щотижневі) та дедлайни в режимах «місяць / тиждень / день» кольорами сфер.
- **Дашборд.** Привітання залежно від часу доби, найближчі (3 дні) й прострочені дедлайни, заняття на сьогодні, загальний прогрес і **🔥 серія днів** — скільки днів поспіль виконано хоча б одне завдання.
- **Статистика.** Графіки Recharts: прогрес за курсами, виконані завдання за 4 тижні, розподіл за сферами.
- **Нагадування.** Сповіщення браузера за 24 години до дедлайну з м'яким звуковим сигналом (Web Audio API, вибір мелодії та гучності), листи на пошту та Telegram-бот **Cadence Pulse** з командами `/deadlines`, `/today`, `/support`, `/pin`.
- **Зручність.** Миттєве перемикання української та англійської мов (інтерфейс, валідація форм, календар, графіки), світла й темна теми, адаптивна верстка для комп'ютера, планшета й телефона, вбудована інструкція користувача.

```text
Cadence-Planner/
├── client/                     # Клієнтська частина (React + Vite)
│   ├── public/images/          # Зображення інтерфейсу
│   └── src/
│       ├── api/                # Axios-клієнт із JWT
│       ├── components/         # Спільні компоненти (меню, модальні вікна, сповіщення)
│       ├── context/            # Авторизація, тема, мова, сповіщення
│       ├── i18n/               # Тексти інтерфейсу: uk.js, en.js
│       ├── pages/              # Сторінки застосунку
│       ├── tests/              # Тести Vitest
│       └── utils/              # Допоміжні функції
├── server/                     # Серверна частина (Express + SQLite)
│   ├── index.js                # Точка входу: база, демо-дані, Telegram-бот, HTTP-сервер
│   ├── app.js                  # Налаштування Express і маршрутів
│   ├── db/                     # Схема бази даних і демо-дані
│   ├── middleware/             # Перевірка JWT
│   ├── routes/                 # Маршрути API
│   ├── controllers/            # Обробка HTTP-запитів
│   ├── services/               # Бізнес-логіка (прогрес, серія днів, пошта, бот, відновлення пароля)
│   └── tests/                  # Тести Jest + supertest
├── .env.example                # Шаблон налаштувань
└── README.md
```

Архітектура сервера шарова: **routes → controllers → services → db**. Маршрути лише визначають адреси, контролери розбирають запит і формують відповідь, сервіси містять бізнес-логіку, а шар `db` працює з базою.

## Встановлення та запуск

Потрібно: **Node.js 20 або новіший** і **Git**.

### 1. Завантаження та встановлення залежностей

```bash
git clone https://github.com/anastasiia7dyshliuk/Cadence-Planner.git
cd Cadence-Planner
npm run install:all
```

### 2. Налаштування (необов'язково)

Застосунок працює й без налаштувань. Щоб увімкнути пошту та Telegram-бота, скопіюйте `.env.example` у `server/.env` і заповніть потрібні рядки:

| Змінна                                | Призначення                                                           |
| :------------------------------------ | :-------------------------------------------------------------------- |
| `APP_URL`                             | Адреса застосунку (для посилань у листах і в боті)                    |
| `JWT_SECRET`                          | Секрет для підпису токенів (обов'язково на сервері в інтернеті)       |
| `TELEGRAM_BOT_TOKEN`                  | Токен бота від @BotFather                                             |
| `BREVO_API_KEY`, `EMAIL_FROM`         | Надсилання листів через Brevo (працює на хостингах, що блокують SMTP) |
| `SMTP_HOST`, `SMTP_USER`, `SMTP_PASS` | Альтернатива: надсилання через SMTP, наприклад Gmail                  |

Файл `server/.env` містить секрети і не потрапляє в git.

### 3. Запуск

Потрібні два термінали.

**Сервер** (API на `http://localhost:5000`):

```bash
cd server
npm run dev
```

**Клієнт** (інтерфейс на `http://localhost:5173`):

```bash
cd client
npm run dev
```

Відкрийте **http://localhost:5173** у браузері.

## Як користуватися

Покрокова інструкція з прикладами екранів є в самому застосунку — розділ **«Інструкція»** в меню. Коротко:

1. **Сфери** — великі напрями життя (навчання, робота, спорт). П'ять стартових сфер створюються автоматично.
2. **Курси** — конкретні предмети чи проєкти всередині сфери. Їх прогрес рахується сам.
3. **Завдання** — домашні справи з дедлайнами. Виконане завдання позначається кружечком або статусом «Виконано». Кожен день із виконаним завданням подовжує 🔥 серію днів на дашборді.
4. **Календар** — заняття за розкладом (можна повторювати щотижня) і дедлайни.
5. **Telegram-бот** — нагадування в месенджері (див. нижче).
   Повернутися на головну можна, натиснувши логотип угорі зліва або пункт «Дашборд»; на попередню сторінку — кнопкою «Назад» у браузері.

### Підключення Telegram-бота

Telegram не дозволяє ботам писати користувачам першими, тому прив'язка відбувається через посилання з одноразовим кодом:

1. Відкрийте **Профіль** → блок «Нагадування через Telegram-бота».
2. Натисніть **«Написати мені в Telegram»** (або «Відкрити бота в Telegram») — відкриється чат із ботом, код уже підставлений.
3. У Telegram натисніть **«Почати»**. Бот прив'яже акаунт, надішле привітання й закріпить угорі чату посилання на застосунок зі списком команд.
4. Поверніться на сайт — статус підключення оновиться автоматично.
   Після прив'язки кнопка «Написати мені в Telegram» надсилає привітання від бота. Команди: ⏰ `/deadlines` — дедлайни, 📅 `/today` — заняття на сьогодні, 💙 `/support` — підтримка, 📌 `/pin` — закріпити посилання знову.

**Мова бота.** Бот відповідає мовою, встановленою в самому Telegram (поле `language_code`, яке Telegram передає з кожним повідомленням): англійською, якщо мова Telegram — English, і українською в усіх інших випадках. Меню команд (кнопка «Меню») теж показується відповідною мовою. Привітання, яке надсилає кнопка на сайті, приходить мовою сайту (UA/EN). Автоматичні нагадування про дедлайни надсилаються українською, бо сервер відправляє їх сам за розкладом і не отримує в цей момент даних про мову Telegram користувача.

Щоб перевірити англійську версію: Telegram → Settings → Language → English, перевідкрийте чат із ботом і надішліть `/start` або `/today`.

### Відновлення пароля

На сторінці входу натисніть **«Забули пароль?»**, вкажіть пошту акаунта й введіть 6-значний код, що прийде на пошту (і в Telegram, якщо бот підключено). Код діє 15 хвилин і спрацьовує один раз; новий код можна запросити не частіше ніж раз на хвилину. Якщо пошта не налаштована (локальна розробка), код виводиться в термінал сервера.

## REST API

Усі маршрути, крім реєстрації, входу, відновлення пароля та вебхука Telegram, вимагають JWT-токен.

| Метод                    | Маршрут                              | Опис                                                                                |
| :----------------------- | :----------------------------------- | :---------------------------------------------------------------------------------- |
| `POST`                   | `/api/auth/register`                 | Реєстрація та створення 5 стартових сфер                                            |
| `POST`                   | `/api/auth/login`                    | Вхід і отримання токена                                                             |
| `POST`                   | `/api/auth/logout`                   | Вихід                                                                               |
| `POST`                   | `/api/auth/forgot-password`          | Запит коду відновлення пароля                                                       |
| `POST`                   | `/api/auth/reset-password`           | Зміна пароля за кодом                                                               |
| `GET` / `PUT`            | `/api/auth/me`                       | Дані поточного користувача / оновлення профілю                                      |
| `GET` / `POST`           | `/api/areas`                         | Список сфер / створення                                                             |
| `GET` / `PUT` / `DELETE` | `/api/areas/:id`                     | Сфера: перегляд / зміна / видалення                                                 |
| `GET` / `POST`           | `/api/courses`                       | Список курсів (`?areaId=`) / створення                                              |
| `GET` / `PUT` / `DELETE` | `/api/courses/:id`                   | Курс: перегляд / зміна / видалення                                                  |
| `GET` / `POST`           | `/api/tasks`                         | Завдання (`search`, `areaId`, `courseId`, `status`, `priority`, `sort`) / створення |
| `GET`                    | `/api/tasks/upcoming?days=3`         | Найближчі дедлайни                                                                  |
| `GET` / `PUT` / `DELETE` | `/api/tasks/:id`                     | Завдання: перегляд / зміна / видалення                                              |
| `POST`                   | `/api/tasks/:id/renew`               | Перенести повторюване завдання на наступний цикл                                    |
| `GET` / `POST`           | `/api/events`                        | Заняття / створення                                                                 |
| `GET` / `PUT` / `DELETE` | `/api/events/:id`                    | Заняття: перегляд / зміна / видалення                                               |
| `GET`                    | `/api/stats`                         | Статистика прогресу й серія днів                                                    |
| `GET` / `PUT`            | `/api/integrations`                  | Налаштування нагадувань (пошта, Telegram)                                           |
| `POST`                   | `/api/integrations/telegram/webhook` | Вхідні повідомлення Telegram-бота                                                   |

## Відомі обмеження

- База даних SQLite розрахована на одного або невелику кількість одночасних користувачів.
- Сповіщення браузера надходять лише тоді, коли вкладка застосунку відкрита і користувач дав дозвіл.
- На безкоштовному хостингу з тимчасовою файловою системою дані скидаються до демонстраційних після перезапуску сервера. Для постійного зберігання потрібна хмарна база (наприклад, PostgreSQL).
